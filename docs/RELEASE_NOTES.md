## 2.0.49 内置字典与界面完善

- 新增「常见密码字典」官方示例，首次启动即可直接选用。
- 字典破解支持起始行、断点续跑；中止保留当前行，继续按钮接着跑。
- 升级 7-Zip ZS 26.05 引擎，修复 ZSTD 编码 7z 解压失败。
- 修复超长路径拖放解压报错（0x80070003 与资源管理器磁盘错误）。
- 所有提示、确认和错误弹窗统一为 Fluent 样式，跟随浅色/深色主题。
- 目录树展开收起、列表悬浮选中、平滑滚动与页面切换加入过渡动画。
- 密码框「常用密码」按钮与「显示密码」按钮尺寸、位置和悬停效果对齐。
- 关于页文案调整为「云密码搜索 / 依赖KeyFetch / 仅在许可情况下匿名上传」。
- 安装器始终显示「选择安装位置」，覆盖升级会预填原安装目录。

常规版运行安装包覆盖升级；Portable 更新请保留整个 Data 文件夹。
