## 下载

- **常规安装版（推荐）**：`Zipora-v2.0.47-Setup-x64.exe`。自动识别旧安装目录覆盖升级，保留本机 AppData 中的设置和密码库。
- **Portable**：`Zipora-v2.0.47-win-x64-portable.zip`。完整解压后运行 `Start-Zipora.cmd` 或 `App/Zipora.exe`，升级时保留整个 Data。
- **常规 ZIP**：`Zipora-v2.0.47-win-x64.zip`，数据保存在本机 AppData。

适用于 Windows 10 1809 / Windows 11 x64，包含 .NET 运行库和官方 7-Zip 26.03 引擎，无需另装 .NET。校验值见 SHA256SUMS.txt。

## 更新内容

- 新增 Zip Slip 防护，默认开启，可在设置中关闭；打开压缩包、显示内容前自动检查危险路径、链接和路径冲突，提取前再次验证。
- Ctrl 按住后可从文件条目开始框选；完善增减选择、边缘滚动、滚轮、Esc 取消和失焦恢复，保留普通拖拽解压。
- 优化提示弹窗：短消息按内容收紧，长说明滚动，按钮始终可见；完善 Enter 和 Esc 操作，危险确认默认保持安全选项。
- 精简主菜单，检查更新仅保留在设置中；移除系统右键菜单、密码管理、密码上传的说明图标，Portable 不可用的右键菜单卡片提供悬停提示。
- 修复防护设置在 U 盘写保护、断开或磁盘空间不足时保存失败可能导致的异常；失败时说明未保存，并保留本次会话选择。
- 常规版与 Portable 同步上述功能与界面。

## 注意

Zip Slip 防护是路径安全检查，不代替病毒扫描。无法完整验证原始文件名的部分特殊/分卷 ZIP 会被阻止，具体范围见源码 docs/PATH-SAFETY.md。关闭增强防护仍保留原有基本路径边界检查。

安装器支持旧目录识别与覆盖升级。升级前关闭程序；不要覆盖 Portable 目录。普通版 DPAPI 密码库与 Portable 主密码密码库不能直接互换。

客户端仅包含 KeyFetch 公开 API 调用，不包含服务端、部署文件、服务密钥或个人数据。
