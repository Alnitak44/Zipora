## 下载

- **常规安装版（推荐）**：`Zipora-v2.0.39-Setup-x64.exe`。支持选择目录、开始菜单/桌面快捷方式、可选右键菜单、覆盖升级与卸载。再次运行安装包会识别旧安装目录，设置和密码库保留在本机 AppData。
- **Portable**：`Zipora-v2.0.39-win-x64-portable.zip`。完整解压后运行 `Start-Zipora.cmd` 或 `App/Zipora.exe`，升级保留 Data。
- **常规 ZIP**：`Zipora-v2.0.39-win-x64.zip`。完整解压后运行 Zipora.exe，数据保存在本机 AppData。

适用于 Windows 10 1809 / Windows 11 x64，包含 .NET 运行库和官方 7-Zip 26.03 引擎，无需另装 .NET。下载校验见 SHA256SUMS.txt。

## 更新内容

- 新增常规版安装器，自动识别安装目录并覆盖升级，保留用户设置、密码库和自建字典。运行中的程序会阻止覆盖；右键扩展被占用时可能需要重启完成替换。
- 常规版与 Portable 同步最新设置界面、新图标、固定比例背景裁切与背景即时刷新修复。
- 新增 GitHub 更新检测，支持每次、每天、每周、每2周、每月、永不；常规版优先下载安装包。
- 优化密码管理与密码快速填入、文件选择和拖拽解压，修复没有字典时打开字典破解窗口崩溃。
- 简化设置说明、菜单文案与卡片布局；保留 Info 悬停说明，恢复便携模式常驻提示。
- KeyFetch 云查询可直接使用，保留每日配额与本地限流；客户端不包含服务端访问密钥，服务端及部署配置不在开源仓库中。

安装升级不转换 Portable 的主密码密码库与常规版的 Windows 用户加密密码库。不要让安装器覆盖 Portable 目录；常规版和 Portable 可以并存。

## 验证

发行前执行解压、输出文件名、背景/更新/字典窗口回归，并在临时 Windows 构建环境验证安装、自定义目录识别、程序覆盖、右键菜单注册/卸载及用户数据保留。真实 U 盘掉电、多用户/跨机、资源管理器长期占用扩展以及实际 UAC 流程仍需按使用环境验收。
