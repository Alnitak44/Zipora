7-Zip ZS 26.05 (v1.5.7 R1)
---------------------------

7-Zip is a file archiver for Windows.

7-Zip Copyright (C) 1999-2026 Igor Pavlov.

This is the 7-Zip ZS build by Tino Reichardt, Sergey G. Brester and fzxx,
based on 7-Zip 26.05. It adds ZSTD, BROTLI, LZ4, LZ5 and LIZARD codecs, so
archives produced by other tools with those methods can be extracted.
Project page: https://github.com/mcmilk/7-Zip-zstd
See NOTICE-ZS.txt in this folder for version and license details.

The main features of 7-Zip:

  - High compression ratio in the new 7z format
  - Supported formats:
     - Packing / unpacking: 7z, XZ, BZIP2, GZIP, TAR, ZIP and WIM.
     - Unpacking only: APFS, AR, ARJ, Base64, CAB, CHM, CPIO, CramFS, DMG, EXT, FAT, GPT, HFS,
                       IHEX, ISO, LZH, LZMA, MBR, MSI, NSIS, NTFS, QCOW2, RAR,
                       RPM, SquashFS, UDF, UEFI, VDI, VHD, VHDX, VMDK, XAR, Z and ZSTD.
     - ZS extras: packing/unpacking ZSTD, BROTLI, LZ4, LZ5 and LIZARD.
  - Fast compression and decompression
  - Self-extracting capability for 7z format
  - Strong AES-256 encryption in 7z and ZIP formats
  - Integration with Windows Shell
  - Powerful File Manager
  - Powerful command line version
  - Localizations for 90 languages
